What makes this form accessible

Real labels

Every input has a <label for>, so clicking the label focuses the field and screen readers read it. Placeholders are only examples.

Clear errors

Errors appear in text next to the field (not only red borders), are linked with aria-describedby, and set aria-invalid.

Helpful input

autocomplete, inputmode="numeric" and a show-password option make typing easier for everyone.

What I learned

  • WCAG 1.3.1 Info and Relationships: fieldset and legend group related fields.
  • WCAG 3.3.1 Error Identification: say in text what is wrong, and where.
  • WCAG 3.3.2 Labels or Instructions: show the rules (such as "exactly 9 digits") before the user makes a mistake.
  • WCAG 1.3.5 Identify Input Purpose: autocomplete="name" and "email" let browsers fill fields in.
  • On submit, focus moves to the first invalid field, so keyboard users don't get lost.
